# OpenQuant 52 课完整路线图 v1.0

> 面向中国大陆软件工程师的个人量化投资训练计划。初始资金 5 万元，长期方向为价值投资 + 量化增强 + AI 辅助研究。20% 年化仅作为有挑战性的研究目标，不是收益承诺或毕业标准。

## 当前进度

- Lesson 01：股票是什么？为什么要量化投资？ ✅ 已完成
- Lesson 02：A股市场结构与投资工具 ✅ 已完成
- Lesson 03：复利、收益与财富目标 🚧 进行中
- 总进度：2 / 52 完成

## 个人投资约束

- 初始配置框架：ETF 60% / 量化策略 30% / 现金与实验 10%
- 不买看不懂的企业
- 不买无法证明盈利能力的企业
- 量化决策必须经过数据验证
- 家庭资金安全和长期生存优先于短期收益
- 第一年不做杠杆、打板、高频、复杂衍生品投机或无人值守实盘

## 每课固定工作流

1. 理论学习与资料核验
2. 编码、案例研究或数据实验
3. 作业与独立验证
4. GitHub 归档、测试和复盘

每课默认归档到：

```text
docs/lessons/lesson-xx/
├── README.md
├── notes.md
├── homework.md
└── references.md
```

涉及代码的课程还必须交付可运行代码、自动化测试、实验结果、结论与局限。

## 毕业标准

1. 能独立提出投资假设并说明经济逻辑。

3. 能实现包含A股交易约束和成本的可复现回测。

## 第一年明确不做
